\section{Robotics and Control Projects}
\project{Wheeled-Bipedal Robot Modeling and CLF-MPC Control}{MATLAB/Simulink, CasADi, C++, Gazebo}{Sep.\ 2024 -- Oct.\ 2025}
\cvItemsStart
\item Derived and implemented nonlinear wheeled inverted pendulum dynamics, equilibrium analysis, and numerical state propagation for a wheeled-bipedal robot.
\item Implemented constrained model predictive control with Control Lyapunov Function conditions, forward-velocity references, actuator limits, and control smoothness penalties.
\item Generated polynomial height trajectories with prescribed endpoint conditions and analyzed position, velocity, acceleration, and jerk.
\item Built a Gazebo--Simulink co-simulation interface using a C++ plugin and Protocol Buffers to exchange joint states, IMU measurements, and motor-torque commands.

\project{RS-JiLQG for Nonlinear Stochastic Systems with Slip Jumps}{Graduate stochastic control project; Python, NumPy}{Sep.\ 2024 -- Oct.\ 2025}
\cvItemsStart
\item Co-developed a risk-sensitive jump iterative Linear Quadratic Gaussian formulation for nonlinear systems subject to diffusion noise and intermittent slip disturbances.
\item Implemented a dedicated solver with backward policy updates, feedback and feedforward control, regularization, forward rollout, and line search.
\item Built wheeled inverted pendulum dynamics, closed-loop Monte Carlo simulations, risk-parameter sweeps, and result exports for expected and entropic cost.
\item Added LQR baselines, extended and unscented Kalman filters, disturbance scenarios, and tools for failure-rate and conditional-value-at-risk evaluation.
\cvItemsEnd
